# 0.4 — Unified Esc / leave to Home

**Phase:** 0 · Happy path  
**Status:** Decisions locked — see [../../DECISIONS.md](../../DECISIONS.md)  
**Visual change:** No (behavior + help copy; tiny footer label changes only)  
**Risk:** Medium (key semantics across monitor/review/root)  
**Depends on:** 0.1 (Home as leave target)  
**Primary surfaces:** `internal/tui` root, `internal/tui/monitor`,
`internal/tui/review`, help sections

## Problem

Escape/`q`/`h`/`backspace` overlap with different leave behaviors:

- Steps: esc/q/backspace/h → runs list
- Transcript: esc/h → Steps; q → runs list
- Gate: esc → blur or nested back
- Review workspace: esc → close/cancel depending on mode

Operators cannot form a reliable mental model. Lazygit’s strength is a strict
one-level back stack.

## Goal

**Esc dismisses the innermost layer** (or leaves Monitor from Steps).  
**`q` leaves Monitor → Home** from Steps or Transcript.  
Arrow/`h` may remain as vim pane peers but must not skip levels or leave Monitor.

## Locked decisions

| ID | Lock |
|---|---|
| A3 | Steps: **Esc and `q` → Home**. Transcript: Esc → Steps; **`q` → Home** |
| A4 | Drop **`h` and `backspace`** as leave keys |
| A6 | Dirty compose/review buffer: **confirm modal** on dirty leave |
| C4 | Esc from Steps is **leave to Home** (not a no-op) |
| D1 | Help-agent: Esc closes modal only (IA redesign later) |
| D3 | Delete confirm: Esc closes confirm only |
| D9 | Reset confirm `y`/`n`: Esc cancels; does not leave Monitor |
| G8 | Preserve tab / 1–9 / ctrl+c / ctrl+o; Esc/`q` remaps intentional |

## Esc ladder (Monitor)

```text
compose/edit comment (dirty → confirm on leave)
  → review browse
    → review workspace closed (gate still focused)
      → gate nested form back (if any)
        → gate blurred → Steps
          → Steps Esc/`q` → Home
Transcript Esc → Steps
Transcript `q` → Home
Help overlay / help-agent / delete confirm / reset confirm:
  Esc closes that overlay only
```

## Implementation sketch

- Change `StepsLeave` to `esc` + `q` only; destination Home (via 0.1 message).
- Drop `h`/`backspace` from leave bindings; keep panel-focus peers elsewhere.
- Review: browse Esc closes workspace without submitting; compose Esc cancels
  compose only; dirty leave triggers confirm (A6).
- Root: Monitor leave message becomes Home equivalent from 0.1.
- Update help strings: `esc home` / `q home` on Steps; `esc steps` / `q home`
  on Transcript.
- Table-driven tests for each layer’s Esc.
