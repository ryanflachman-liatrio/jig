# 0.4 — Unified Esc “back one level”

**Phase:** 0 · Happy path  
**Status:** Proposed  
**Visual change:** No (behavior + help copy; tiny footer label changes only)  
**Risk:** Medium (key semantics across monitor/review/root)  
**Primary surfaces:** `internal/tui` root, `internal/tui/monitor`,
`internal/tui/review`, help sections

## Problem

Escape/`q`/`h`/`backspace` overlap with different leave behaviors:

- Steps: esc/q/backspace/h → runs list
- Transcript: esc/h → Steps; q → runs list
- Gate: esc → blur or nested back
- Review workspace: esc → close/cancel depending on mode

Operators cannot form a reliable mental model. Lazygit’s strength is a strict
one-level back stack.

## Goal

**Esc always means: dismiss the innermost layer.**  
**`q` means: leave the current top-level surface (Monitor → Home).**  
Arrow/`h` may remain as vim pane peers but must not skip levels.

## Proposed Esc ladder (Monitor)

```text
compose/edit comment
  → review browse
    → review workspace closed (gate still focused)
      → gate blurred → Steps
        → (Esc on Steps does nothing destructive; use q to Home)
```

## Decisions to lock

1. **Esc vs q:** Esc = inward stack; q = exit Monitor to Home (confirm if a
   destructive compose buffer is dirty? prefer soft: Esc clears dirty compose
   first).
2. **Transcript Esc:** always Steps (keep). Never Runs.
3. **Steps Esc:** no-op or focus Transcript? Prefer **no-op** so Esc never
   surprises; `q` leaves. Remove Esc from `StepsLeave` if it currently jumps to
   Runs.
4. **Gate Esc:** nested form back if any; else blur to Steps (keep).
5. **Help overlay Esc:** close overlay only (root already owns this).
6. **Document** the ladder in `?` Global/Focus sections as one short paragraph
   worth of bindings, not four conflicting leave keys.

## Implementation sketch

- Change `StepsLeave` to drop `esc` (keep `q` for Home; optionally keep
  `backspace` only if we want a secondary — prefer just `q`).
- Review: ensure browse-mode Esc closes workspace without submitting; compose
  Esc cancels compose only.
- Root: Monitor leave message stays `ShowRunsMsg` / Home equivalent from 0.1.
- Update help strings: `esc back` / `q home` consistently.
- Table-driven tests for each layer’s Esc.

## Acceptance

- [ ] From compose comment, one Esc returns to review browse (not gate, not home)
- [ ] From review browse, Esc closes workspace to gate
- [ ] From gate, Esc blurs to Steps
- [ ] From Steps, Esc does not leave Monitor
- [ ] From Steps, `q` returns Home
- [ ] From Transcript, Esc → Steps; `q` → Home
- [ ] Help overlay copy matches behavior
