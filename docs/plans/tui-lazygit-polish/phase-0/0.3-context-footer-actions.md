## Problem

*(Rewritten per B3 / E7.)* `CompactHint` already skips `!Enabled()` bindings.
The real pain is:

1. **Ordering / width budget** — too many chords, or truncation to `? more` so
   aggressive that operators never learn the three keys they need
2. **Remapped keys** — same physical key changes meaning (`r` = new run / reset /
   retry / finalize) without the footer label updating in lockstep
3. **Home parity** — ad-hoc footers on selector/runs/detail don’t share Monitor’s
   “first help section = compact footer” contract

## Goal

Footer shows **only currently valid actions** for the focused region, ordered by
importance, with a stable discoverability escape hatch (`?` / `F1` → `more`).

## Decisions (item-local, still in force)

1. **Source of truth:** footer bindings = first help section for current focus —
   extend to Home.
2. **Ordering:** primary verb first (enter/open/submit), then navigation, then
   secondary, then `more`. Never lead with quit.
3. **Atomic admission:** keep `CompactHint` (never clip mid-binding).
4. **Remapped keys:** footer label updates in the same Update cycle as enablement.
5. **Width budget:** at 80 cols show ≥ 3 contextual actions + `more` when any
   contextual actions exist.

## Implementation sketch

- Inventory every `footerView` / `HintString` call site; shared
  `FooterBar{Status, Bindings}` helper if duplication hurts.
- Ensure lifecycle `SetEnabled` paths stay the only gate for stop/reset/resume.
- Golden string tests at 80 and 120 columns for Steps / Transcript / Gate /
  Review-open / Home.
- Copy-edit help strings to verb+object (`open run`, not just `monitor`).

## Acceptance

- [ ] No footer advertises a disabled action (regression guard on CompactHint)
- [ ] At 80 columns, Monitor waiting-on-gate shows status + ≥2 gate actions + more
- [ ] Switching focus updates footer labels before next key is processed
- [ ] `?` / `F1` still opens the full overlay with sections
- [ ] Home footers use the same contract as Monitor
- [ ] Quit remains available in help overlay; optional in footer only if space


