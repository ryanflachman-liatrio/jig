# 0.1 — Flatten home navigation

**Phase:** 0 · Happy path  
**Status:** Decisions locked — see [../../DECISIONS.md](../../DECISIONS.md)  
**Visual change:** Yes  
**Risk:** Medium (screen graph / root routing)  
**Primary surfaces:** `internal/tui` (root), `internal/tui/selector`,
`internal/tui/runs`, `internal/tui/detail`

## Problem

Today the operator travels **Workflows → Detail → Runs → Monitor**. Empty Runs
even tells you to leave and press `r` on Detail. Lazygit never sends you
somewhere else to act — the workspace is one composition.

## Goal

Collapse to **two surfaces**:

1. **Home** — workflows + runs side-by-side
2. **Monitor** — the primary app once a run is open

## Locked decisions

| ID | Lock |
|---|---|
| A1 | Cold start **auto-selects the first workflow**; right pane shows its runs |
| A2 | Detail/chart is a **`d` overlay** (not a root screen); chart stays there |
| A7 | Keep switch-based root; **amend ADR 0004** (no Screen interface in this item) |
| D3 | Home runs pane keeps **`d` delete** + confirm overlay (Runs-focused only) |
| D4 | Home runs pane keeps **`R` resume** |
| D5 | Workflow **`/` filter** on Home |
| D7 | Hydrate-on-startup into Home runs pane |
| D8 | `internal/tui/chat` stays **out** |
| G2 | `enter` on workflow → **focus Runs pane**; **`d` on Workflows** → Detail overlay |
| G3 | `enter` on run → **Monitor** always |
| G1 | Short run id = **8 hex** in lists/status |

Note: **`d` is pane-scoped** — Workflows focus → Detail overlay; Runs focus →
delete confirm. Footer labels must follow focus (0.3).

## Implementation sketch

- Introduce `screenHome` (or evolve selector into a dual-panel home model) that
  owns workflow list + embedded runs list.
- Root `Update` routes: Home ↔ Monitor; demote `screenDetail` / `screenRuns` as
  top-level actives (Detail becomes overlay owned by Home).
- On Init: select first workflow when any exist; filter runs to that workflow.
- Preserve run hydrate-on-startup into the Home runs pane.
- Update help sections + footer bindings for the combined surface.
- Migrate/rewrite selector/runs/detail tests that assert the old stack.
- Amend ADR 0004 text to Home↔Monitor (implementation still pending).

## Acceptance

- [ ] Cold start shows Home with first workflow selected and its runs listed
- [ ] `r` starts a run without visiting Detail
- [ ] Empty runs pane CTA is local (“r new run”), never “go to Detail”
- [ ] `d` opens Detail/chart overlay; Esc closes overlay only
- [ ] `R` resumes a paused run from Home; `d` delete still confirms
- [ ] `/` filters workflows
- [ ] Hydrated runs appear in Home runs pane on startup
- [ ] Monitor leave returns to Home with selection preserved (see 0.4)
- [ ] Narrow terminals stack panes vertically (workflows above runs) instead of
      dropping one pane silently
