# 0.1 — Flatten home navigation

**Phase:** 0 · Happy path  
**Status:** Proposed  
**Visual change:** Yes  
**Risk:** Medium (screen graph / root routing)  
**Primary surfaces:** `internal/tui` (root), `internal/tui/selector`,
`internal/tui/runs`, `internal/tui/detail`

## Problem

Today the operator travels **Workflows → Detail → Runs → Monitor**. Empty Runs
even tells you to leave and press `r` on Detail. Lazygit never sends you
somewhere else to act — the workspace is one composition.

## Goal

Collapse to **two surfaces**:

1. **Home** — workflows + recent runs side-by-side (Detail becomes an optional
   inspect/toggle, not a required hop)
2. **Monitor** — the primary app once a run is open

## Decisions to lock

1. **Home layout:** left = workflow list, right = runs for selected workflow
   (all runs when none selected / global recent). Prefer this over tabs.
2. **Detail chart:** keep as `v` toggle *inside* the workflow pane (or a
   slide-over), not a separate root screen. If Detail must remain temporarily,
   `enter` on a workflow goes Home→right focus on runs with that workflow
   filtered, and `d` opens detail overlay.
3. **Start run:** `r` works from Home when a workflow is selected (and from
   Runs when context carries a workflow). Remove the “go back to Detail” empty
   state copy.
4. **Back from Monitor:** returns to Home with the same workflow/run
   selection restored.

## Implementation sketch

- Introduce `screenHome` (or evolve selector into a dual-panel home model) that
  owns workflow list + embedded runs list.
- Root `Update` routes: Home ↔ Monitor; delete or demote `screenDetail` /
  `screenRuns` as top-level actives.
- Preserve run hydrate-on-startup into the Home runs pane.
- Update help sections + footer bindings for the combined surface.
- Migrate/rewrite selector/runs/detail tests that assert the old stack.

## Acceptance

- [ ] Cold start shows Home with workflows; selecting one filters/highlights runs
- [ ] `r` starts a run without visiting Detail
- [ ] Empty runs pane CTA is local (“r new run”), never “go to Detail”
- [ ] Monitor Esc/q returns to Home with selection preserved
- [ ] Narrow terminals stack panes vertically (workflows above runs) instead of
      dropping one pane silently
