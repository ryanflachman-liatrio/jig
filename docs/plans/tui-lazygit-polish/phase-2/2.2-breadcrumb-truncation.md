# 2.2 — Breadcrumb truncation (run + leaf)

**Phase:** 2 · Remaining friction  
**Status:** Decisions locked — see [../../DECISIONS.md](../../DECISIONS.md)  
**Visual change:** Yes  
**Depends on:** 1.1 (status carries identity), 1.2 (badges)  
**Primary surfaces:** `internal/tui/shared` (`BreadcrumbTitle`), monitor title
parts

## Problem

Titles like
`ab12cd34 · feature › implement › Transcript · PAUSED · 3 new`
fight the panel edge and hide the leaf that matters. Callers pack too many
segments even though BreadcrumbTitle tries to preserve root+leaf.

## Goal

Panel titles prefer **run · leaf** (and focus badge). Mid hierarchy and
LIVE/PAUSED/unseen move to the status line (1.1) — not the border title.

## Locked decisions

| ID | Lock |
|---|---|
| C2 | TARGET already matches this end state |
| C1 | LIVE / `N new` live on status, not footer state words |
| G5 | Unseen count on status only |
| G1 | Short run id (8 hex) available for titles |

## Item decisions

1. Steps title: `shortRun · [STEPS]` / `shortRun · Steps`
2. Transcript title: `stepID · [TRANSCRIPT]` (+ `· LIVE` only if it fits after badge)
3. Unseen count: status line only
4. Workflow name: status line owns it; optional in Steps title only when width abundant
5. Keep BreadcrumbTitle algorithm; reduce inputs

## Implementation sketch

- Slim `stepsPanelTitleParts` / `transcriptPanelTitleParts`.
- LIVE/PAUSED/unseen → status line fields (1.1).
- Tests for title strings at widths 40/80/120.

## Acceptance

- [ ] Default ~100-col layout titles do not mid-word-ellipsis normal ids
- [ ] Unseen count still visible on status when &gt; 0
- [ ] Focus badge retained under truncation pressure (1.2)
