# 2.2 — Breadcrumb truncation (run + leaf)

**Phase:** 2 · Remaining friction  
**Status:** Proposed  
**Visual change:** Yes  
**Depends on:** 1.1 (status line carries identity), 1.2 (badges)  
**Primary surfaces:** `internal/tui/shared` (`BreadcrumbTitle`), monitor title
parts

## Problem

Titles like
`ab12cd34 · feature › implement › Transcript · PAUSED · 3 new`
fight the panel edge and hide the leaf that matters. BreadcrumbTitle already
tries root+leaf preservation; callers still pack too many segments.

## Goal

Panel titles prefer **run · leaf** (and focus badge). Mid hierarchy and LIVE/
PAUSED counters move to the status line (1.1) or a quiet subtitle row inside the
panel body — not the border title.

## Decisions to lock

1. **Steps title:** `shortRun · [STEPS]` or `shortRun · Steps`
2. **Transcript title:** `stepID · [TRANSCRIPT]` (+ optional `· LIVE` only if it
   fits after badge)
3. **Unseen count:** move to status line (`3 new`) or first body row, not title
4. **Workflow name:** status line owns it; optional in Steps title only when
   width abundant
5. Keep BreadcrumbTitle algorithm; reduce inputs

## Implementation sketch

- Slim `stepsPanelTitleParts` / `transcriptPanelTitleParts`.
- LIVE/PAUSED/unseen → status line fields.
- Tests for title strings at widths 40/80/120.

## Acceptance

- [ ] Default 100-col layout titles do not end with `…` mid-word for normal ids
- [ ] Unseen count still visible somewhere when > 0
- [ ] Focus badge retained under truncation pressure (see 1.2)
