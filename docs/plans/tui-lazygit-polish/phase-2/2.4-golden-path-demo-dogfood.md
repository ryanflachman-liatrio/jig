## Problem

Without a scripted happy path, polish regresses. “Feels like Lazygit” is not a
unit test — it needs a repeatable operator story.

## Goal

1. A **≤60s golden-path script** (keys only) from cold start → answer gate → home
2. Capture screenshots or asciinema for Home, Monitor running, Gate, Review
3. Checklist used in PR review for any TUI change touching navigation/focus/footer

## Golden path (draft)

```text
1. jig                         → Home (first workflow auto-selected)
2. j/k select workflow         → feature highlighted (if not first)
3. r                           → run starts, Monitor opens
4. observe Steps + Transcript  → follow LIVE
5. wait for gate (deterministic review/command workflow)
6. tab (if needed)             → [GATE]
7. enter                       → [REVIEW] (if review) OR 1 approve
8. S / decide                  → submit
9. q                           → Home, run listed
```

Every unexpected Esc, focus jump, or missing footer verb is a bug against Phase 0
contracts.
