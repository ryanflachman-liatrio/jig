# 2.3 — Simple mode (progressive disclosure)

**Phase:** 2 · Remaining friction  
**Status:** Proposed  
**Visual change:** Yes (fewer chrome affordances; optional banner)  
**Depends on:** 0.3, 1.3  
**Primary surfaces:** monitor keys/help/footer, optional config flag

## Problem

Paging (`[`/`]`), filters (`F`), expand-all (`o`), block nav, search — all
valuable, all noisy for someone who only wants to watch a run and answer a gate.

## Goal

A **simple mode** that hides advanced transcript affordances from footer/help
until toggled, without removing capabilities.

## Decisions to lock

1. **Default:** simple mode ON for first-run / until user toggles (or OFF if we
   fear surprising power users — prefer ON for “usable,” document in README).
   Decision: **default ON for new installs; persist preference in
   `.jig/tui.json` or similar.**
2. **Hidden in simple:** transcript search, filters, page older/newer, expand
   all, block-nav chords (keep j/k scroll + follow + enter expand).
3. **Always available:** focus tab, gate actions, lifecycle stop/reset when
   enabled, `?`, palette (`ctrl+k`) which still lists advanced commands.
4. **Toggle:** `ctrl+shift+a` or palette “Enable advanced controls” — avoid
   stealing `a` from abort.
5. **Indicator:** quiet footer tag `simple` / `advanced` or status-line chip.

## Implementation sketch

- `Model.simple bool` loaded from small config.
- Filter bindings in `compactHelpBindings` / HelpSections.
- Palette always full for discoverability.
- Tests for binding enablement matrix.

## Acceptance

- [ ] Simple mode footer omits `[` `]` `F` `/` `o` `n/N` (unless search active
      exception — prefer omit search entry too)
- [ ] Palette can still run “Search transcript”
- [ ] Toggle persists across sessions
- [ ] Help overlay states which mode is active

## Expected UI (after)

### Simple

```text
 ab12 · feature · implement · running
  running · j/k scroll · f follow · enter expand · esc steps · ? more
                                                    └ tag: simple
```

### Advanced

```text

  running · j/k · f follow · / search · F filters · [ ] page · ? more
                                                    └ tag: advanced
```

```text
  (wall of chords)
```
