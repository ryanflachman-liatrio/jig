# 2.3 — Simple mode (progressive disclosure)

**Phase:** 2 · Remaining friction  
**Status:** Decisions locked — see [../../DECISIONS.md](../../DECISIONS.md)  
**Visual change:** Yes (fewer chrome affordances; optional quiet tag)  
**Depends on:** 0.3, 1.3  
**Primary surfaces:** monitor keys/help/footer, `.jig/tui.json`

## Problem

Paging (`[`/`]`), filters (`F`), expand-all (`o`), block nav, search — all
valuable, all noisy for someone who only wants to watch a run and answer a gate.

## Goal

A **simple mode** that hides advanced transcript affordances from footer/help
until toggled, without removing capabilities (palette still lists them).

## Locked decisions

| ID | Lock |
|---|---|
| C5 | Default **ON** for new installs; persist preference |
| E6 | Config path = **`.jig/tui.json`** |
| G6 | Toggle = **`ctrl+shift+a`** + palette command |
| D10 | Palette remains full; `?` remains reference |

## Item decisions

1. Hidden in simple: transcript search, filters, page older/newer, expand all,
   block-nav chords (keep j/k scroll + follow + enter expand).
2. Always available: focus tab, gate actions, lifecycle stop/reset when enabled,
   `?`, `ctrl+k` palette (lists advanced commands).
3. Indicator: quiet footer tag `simple` / `advanced` or status-line chip.
4. Help overlay states which mode is active.

## Implementation sketch

- `Model.simple bool` loaded/saved via `.jig/tui.json`.
- Filter bindings in `compactHelpBindings` / HelpSections.
- Palette always full for discoverability.
- Tests for binding enablement matrix + persistence round-trip.

## Acceptance

- [ ] Simple mode footer omits `[` `]` `F` `/` `o` `n/N` (search entry omitted too)
- [ ] Palette can still run “Search transcript”
- [ ] Toggle persists across sessions in `.jig/tui.json`
- [ ] Default for missing config file is ON
- [ ] Help overlay states which mode is active
