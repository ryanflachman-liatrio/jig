# 1.2 — Panel focus badges

**Phase:** 1 · Lazygit feel  
**Status:** Proposed  
**Visual change:** Yes  
**Depends on:** — (pairs well with 0.2)  
**Primary surfaces:** `internal/tui/shared` panel titles, monitor layout titles

## Problem

Focus is signaled mainly by Charple vs Iron border color. That works when you
already know the system; it is weak when three regions exist (Steps /
Transcript / Gate) and titles are long breadcrumbs. Operators ask “where will
`j` go?”

## Goal

Make focus legible from the **title text** as well as the border:

- Focused panel title uses a clear badge: `[STEPS]`, `[TRANSCRIPT]`, `[GATE]`
- Blurred panels keep plain titles
- Badge is stable width-ish so layout does not jump

## Decisions to lock

1. **Badge vocabulary:** uppercase short names in brackets (Lazygit-ish), not
   icons-only.
2. **Combine with breadcrumbs:** badge replaces the leaf role word when focused:
   `ab12 · feature › [STEPS]` not `ab12 · feature › Steps › [STEPS]`.
3. **Gate:** when gate focused, gate title gets `[GATE]`; steps/transcript stay
   unbadged.
4. **Narrow single-panel mode:** badge still required (border alone is not enough
   when only one panel shows).
5. **Accessibility:** do not rely on color alone (this item is the text channel).

## Implementation sketch

- Title builders (`stepsPanelTitleParts`, transcript parts, gate header) accept
  `focused bool` and inject badge.
- Shared helper `FocusTitle(name string, focused bool) string`.
- Snapshot/string tests for focused vs blurred titles.
- Ensure truncation (BreadcrumbTitle) keeps badge when present — badge is part of
  the leaf segment.

## Acceptance

- [ ] Exactly one region shows a `[NAME]` badge at a time (or none if help modal?)
- [ ] Tab cycles update badge + border together
- [ ] Truncation never strips the badge while leaving a long run id
- [ ] Review workspace (pre-2.1) either hosts its own badge or defers — document
      choice in item 2.1

## Expected UI (after)

### Steps focused

```text
╭─ ab12 · feature › [STEPS] ─╮╭─ implement › Transcript ──────╮
│ ▌ implement ● running      ││ assistant…                    │
╰─ Charple ──────────────────╯╰─ Iron ────────────────────────╯
```

### Transcript focused

```text
╭─ ab12 · feature › Steps ───╮╭─ implement › [TRANSCRIPT] · LIVE ─╮
│   implement ● running      ││ ▌ assistant…                      │
╰─ Iron ─────────────────────╯╰─ Charple ─────────────────────────╯
```

### Gate focused

```text
╭─ ab12 · feature › Steps ───╮╭─ review › Transcript ─────────╮
│   review ● waiting         ││ …                             │
╰─ Iron ─────────────────────╯╰─ Iron ────────────────────────╯
╭─ [GATE] · awaiting review ──────────────────────────────────╮
│ 1 approve  2 revise …                                       │
╰─ Charple ───────────────────────────────────────────────────╯
```

### Before

```text
╭─ ab12cd34 · feature › Steps ─╮╭─ implement › Transcript · PAUSED · 3 new ─╮
│ (border color is the only cue)││                                           │
```
