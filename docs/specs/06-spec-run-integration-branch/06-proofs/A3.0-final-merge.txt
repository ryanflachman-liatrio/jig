A3.0 — Final gated merge (run branch → user branch)

Reproduces the approve path of the spec-06-A3 final-merge gate: at run end the run
branch carries one jig-step-tagged commit per mutating step; approving the gate
runs `git merge --no-edit <run-branch>` onto the user's working branch, which
fast-forwards the base HEAD to include every run commit. Discard is simply not
merging — the base is left untouched and the run branch remains for inspection
(see TestFinalMergeDiscardLeavesBase).

FLAG-2 constraint honored: the final-merge gate is a pre-RunFinished completion
step. The scheduler emits FinalMergeRequest, parks (awaitingFinalMerge), and only
after the operator's approve/discard does it emit RunFinished and settle. There is
no RunResumed event and no post-RunFinished scheduler re-entry.
